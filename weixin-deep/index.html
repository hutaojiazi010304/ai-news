⑧ 预览模型硬件标准

Model Hardware Standard（MHS）研究预览版已向首批科研实验室和先进制造商开放，该规范旨在让 AI agent 安全并行操作显微镜、液体处理仪、机械臂等物理设备。MHS 通过标准化驱动程序将硬件集成时间从数周缩短至数小时甚至数分钟，支持 agent 自主执行全天候实验、实时更新参数及无人干预恢复硬件错误。其核心机制是使用“read”“write”等通用原语实现跨设备通信与发现，无需定制转换程序；驱动内置标签允许以自然语言写入设备特性（如机械臂重量），解决传统纸质手册或隐性知识难以被 AI 获取的问题。MHS 兼容任何具备可编程接口的设备且模型无关，可通过 Model Context Protocol 等标准协议访问。此次预览旨在正式开源前与合作方共建安全评估体系及物理设备操作最佳实践。
